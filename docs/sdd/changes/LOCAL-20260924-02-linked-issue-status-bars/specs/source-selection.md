## Изменённые требования

### FR-005: Решение о включении

Система ДОЛЖНА включать подтверждённый HF-эпик, у которого ни резолюция, ни текущий статус не означают отклонение (`Отклонено`, `Отклонён`, `Rejected`, `Не будет выполняться` после нормализации). Другие непустые резолюции сами по себе не исключают эпик. Тип эпика определяется по `epicTypeIds` профиля; поток — по единственному префиксу `[HF]` или `[DF]` текущего статуса. Поле «Вид эпика» не заменяет этот признак. Неэпики и DF исключаются с причиной, неизвестный поток остаётся неразрешённым. Для доски неразрешённые кандидаты блокируют загрузку историй всей выборки.

#### AC-003: Неразрешённый HF

- **ДАНО** среди кандидатов доски есть задача без подтверждённой принадлежности HF или DF.
- **КОГДА** завершается проверка метаданных.
- **ТОГДА** история доски не загружается и аудит показывает причину.
