# Сверка реализации и текущей SDD

Сверка относится к рабочему дереву, а не к коммиту. [Контрольные суммы](evidence/implementation-files.json) связывают проверенную версию с исходными 84 файлами. Приватные данные и сборка в перечень не включены.

| Путь результата | Реализация | Документ и проверка |
| --- | --- | --- |
| Направленные связи → нижние эпики и задачи | `server/jira/adapter.ts`, `server/jira/hierarchy.ts` | FR-031, NFR-001; адаптер, очередь, общие идентичности, ограниченные повторы и защитные пределы |
| Автономная книга → тот же граф | `server/table-hierarchy.ts`, `server/import.ts`, `src/SourceForm.tsx` | FR-033; источник, версия, непрерывная история, старый формат, отрицательные сценарии; Jira не вызывается |
| История → дочерние полосы | `server/related-timeline.ts` | FR-032; миллисекунды, категории и полный словарь, переоткрытие, конечное закрытие и срез |
| Граф → раскрытие → общий календарь | `shared/hierarchy-view.ts`, `src/HierarchyRows.tsx`, `src/RelatedStatusBar.tsx`, `src/App.tsx` | FR-030; оба нормализованных потока, независимые пути, скрытые исключения, 3 масштаба и 200/201 строка. Пользователь подтвердил проверку по ключу; полный ручной протокол не выполнен |
| Сохранение → перезапуск / обновление | `server/hierarchy-schema.ts`, `server/cache.ts`, оба построителя набора | FR-034; срез, новая/удалённая связь, переименование при том же Jira-ID, отказ записи и откат |

Дельты FR-005, FR-030–034, NFR-001 и AC-029–048 перенесены в соответствующие current specs с сохранением формулировок и ID. Определения в current specs уникальны. Выбор автономного файла уточнён в source-selection; project, architecture, domain, operations, README и контракт XLSX согласованы с кодом. Исторические отчёты не переименованы в успешную приёмку.

Валидатор всего репозитория и активного пакета с `--ready` завершился с кодом 0, предупреждений нет. Локальные Markdown-ссылки проверены при текущей актуализации; кодовые файлы совпадают с контрольными суммами последнего прогона. [Прогон после добавления Epic Link](evidence/epic-membership-check.txt): код 0, 309 тестов, 42 файла, TypeScript и сборка.

Режимы диагностического просмотра описаны в operations и README; код `server/app.ts` и `src/App.tsx` проверен `preview-mode.test.tsx`, рабочий ввод трёх CARSDIS — синтетическим `keys-flow.test.tsx`. Живая сверка именно этих трёх CARSDIS в протоколе не заявлена; это не блокирует принятую пользователем проверку по ключу и текущую актуализацию SDD.

T014 выполнена: текущие спецификации, архитектура, ограничения, сводные статусы и ссылки сверены. Пользователь подтвердил проверку по ключу и признал её пока достаточной, поэтому по его поручению документальная сверка завершена без дальнейшего выполнения T012/T013. Эти задачи остаются частичными, их непроверенные случаи сохранены. Пакет активен, T015 не выполнена; архивирование с остатками пользователь не поручал.

По поручению от 29.09.2026 FR-031 / AC-048 включают стандартный состав Epic Link. Delta, current specs, proposal, design, T016, BDD/TDD, архитектура, README и контракт автономного представления состава согласованы. Автоматическое свидетельство есть; живая проверка этого дополнения к T012 выполнена с разрешением на текущую сессию: полный состав 27 + 1 и проекция 25 допустимых задач, см. протокол. FR-005/FR-030 дополнены фактической резолюцией «Не будет выполняться», T016 проверяет общий словарь. После исправления пользователь подтвердил проверку по ключу; более широкий ручной протокол не подразумевается.
