## Исправление по обратной связи: CARSDIS вместо демонстрации

Причина: диагностический сервер отключал Jira, но показывал обычную форму загрузки. Сохранение прежнего набора при ошибке соответствует контракту; ошибочен доступный ввод в экземпляре без Jira.

- Добавлен сквозной сценарий `keys-flow`: после вымышленной книги настоящий локальный API получает три CARSDIS через подменённый Jira gateway, заменяет A-1 ровно тремя запрошенными корнями; раскрытие выводит ключ дочерней задачи CARSDEL-7. Это синтетическая проверка, не свидетельство состава реальных связей.
- Полный прогон: 295 тестов, 41 файл, TypeScript и Vite успешны ([лог](evidence/preview-mode-check.txt)).
- Применение к уже работающим процессам и реальная загрузка трёх CARSDIS пока не выполнены. Sandbox не разрешил остановку старых процессов; запрошено отдельное разрешение на перезапуск вне sandbox и чтение Jira через существующий Keychain. Постоянные права не изменены.
