# Результат реализации — 09–10.11.2026

Пакет реализован по прямому поручению пользователя «Реализуй». Канонический владелец — этот репозиторий; исходный HEAD `4c7b6e04a1569f63932ef4e9802eb05ae1570f2f`. Ранее существовавшие незакоммиченные изменения сохранены. Проверенное поведение перенесено в четыре текущие спецификации; T001–T010 выполнены. Commit и push не выполнялись.

## Реализованное поведение

- FR-054: TEXT, CONTENT, MLE и UX используют точные активные интервалы только при доказанном отсутствии участия в спринтах на срезе. Пустого текущего поля Sprint недостаточно. Истории текущих подзадач имеют прежний приоритет; собственная история задачи используется при доказанно пустом составе.
- FR-036–039, FR-050–051: подтверждённая работа при членстве покрывает целый наблюдаемый спринт. Точная активность без спринтов покрывает только свои даты. Смешанный состав оценивается внутри календарей; полный непустой состав исключительно без спринтов — на всём цикле реализации без Отложено. Неизвестность не становится доказанным простоем.
- FR-053: колонка называется «Без работы», детали показывают область оценки и источники точной активности. Подпись качества истории — «Полная история». При горизонтальной прокрутке чёрные отметки остаются внутри календаря и не перекрывают закреплённые числовые колонки.
- FR-055, FR-023: подтверждённый сброс удаляет данные анализа из кэша и памяти, возвращает пустые поля и исходное представление. Настройки подключения и исходные файлы сохраняются. Защищены занятость, устаревшее подтверждение, повтор, повреждённый кэш, потерянный ответ и поздние ответы прежнего задания.

## Контрольный случай

У TEXT-1314 точная активность 28.07.2026 с 11:21:40 до 18:28:07 по Москве. Она не покрывает августовскую реализацию HOTELS-13142. Поэтому чёрная отметка под «Р» появилась с 18.08.2026 15:12:23.407 до 25.08.2026 12:22:33 по Москве. Она видна на [снимке](evidence/visual/08-hotels-case.png).

Числовые 13,93 суток и длительность этой отметки различаются по согласованным критериям: число требует работы, старая отметка спринтовой задачи — включения. Точные значения, остальные интервалы и границы цикла сохранены в `hotels-case.json`.

Рабочий набор на срезе `2026-11-09T15:05:53.271Z` содержит 154 исходные гипотезы. Его SHA-256 до и после проверок: `d5a1a42d0d9de5bfe0c87a8351813f756e6081ae712f5ae697b882359fe30a69`. Исходные данные не перезаписаны, сброс к ним не применялся, Jira заново не загружалась. Основное приложение оставлено на `http://127.0.0.1:4317/` с прежним контекстом доступа к Keychain.

После архивирования повторно проверены HTTP 200 основного приложения, актуальное число HOTELS-13142 и неизменный хеш: [финальная проверка](evidence/final-runtime-check.json). Временный проверочный сервер остановлен.

## Границы результата

Проверки используют согласованный список проектов и сохранённый срез; они не подтверждают полноту будущих данных Jira. Текущий состав подзадач и прежние ограничения источников сохраняются.
