## Живая Jira — T012

Использован `scripts/verify-linked-acceptance.ts`: только GET, PAT читается внутри процесса из согласованной записи Keychain и не попадает в вывод. Рабочий набор не заменяется; полный ответ Jira не сохраняется. [Протокол](evidence/acceptance-jira-20261111.json) содержит пять успешных групп проверок.

| Проверка | Наблюдение |
| --- | --- |
| Направление связи | BUSDIS-10 содержит BUSDEL-6; у родителя `outwardIssue`, у ребёнка `inwardIssue`, один тип связи `11400`. Производственный адаптер получает одно и то же направленное ребро из обоих ответов |
| Обычная задача и подзадача | У BUSDEL-58 `issuetype.subtask=false`; у BUSDEL-60 — `true`, её `parent.id` совпадает с BUSDEL-58. Адаптер сохраняет признак подзадачи |
| Стандартный состав эпика | RAIL-11361: все 27 задач Epic Link включены адаптером, пагинация завершена, состав полный |
| Категория и точное закрытие | Полные истории BUSDIS-10, BUSDEL-6, RAIL-11361 и BUSDEL-58; категория `done`, окончательные даты полос совпадают с соответствующими переходами |
| Повторное открытие | RAIL-1924: `Closed → Open` 03.07.2019 11:04:13 МСК, окончательное закрытие 21.10.2026 19:35:06 МСК. Полная история сохраняет промежуточное закрытие, конец полосы совпадает с последним закрытием |

Первоначальный поиск по одному закрывающему статусу не дал переоткрытия. В справочнике также нет отдельного названия «Переоткрыта». Итоговый поиск использовал реальные ID завершённых и рабочих статусов в проектах RAIL/BUSDEL; найдено 107 кандидатов, прочитана история первого подходящего RAIL-1924. Это уточнение контрольных данных, не исправление приложения.

**Граница живого свидетельства:** у проверенных задач словарь категорий доступен и полон. Естественный случай недоступной категории не наблюдался. Резерв по названию проверен управляемым повтором тех же пяти живых историй с пустым словарём: состояние полное, источник закрытия `name`, конечные даты совпадают. Автоматические тесты отдельно проверяют отказ справочника и неизвестные категории. Управляемый повтор не объявляется естественным отказом Jira.

11.11.2026 после объяснения способа проверки пользователь ответил «Подтверждаю» на предложение признать управляемый повтор достаточным и архивировать пакет. T012 принята в этом объёме. Естественный случай недоступной категории остаётся ненаблюдавшимся и не объявляется пройденным. [Решение и завершение](archive.md).
