## Ограничения и состояние приложения

Рабочая ссылка: `http://127.0.0.1:4317/`. В единственной гипотезе текущего сохранённого набора точное новое число неизвестно: полнота календаря не подтверждена и данные исторического спринта недоступны. Прочерк с причиной соответствует согласованному поведению; доступные интервалы сохранены. Прежний набор не заменялся контрольными данными.

Текущий состав подзадач остаётся ограничением ADR-0001. Метрика оценивает фокус по спринтам, а не трудозатраты; краткая работа покрывает целый наблюдаемый спринт. Новая возможность не закрывает непроверенные остатки старых пакетов. Commit и push не выполнялись.
