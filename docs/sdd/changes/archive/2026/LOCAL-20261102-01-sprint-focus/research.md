# Проверка текущей реализации

Исходная ревизия: `4c7b6e04a1569f63932ef4e9802eb05ae1570f2f`, ветка `main`, рабочее дерево до подготовки чистое. [Инвентаризация](evidence/inventory.json). Jira и Keychain для подготовки не запрашивались.

| Проверенный факт | Источник | Следствие для дизайна |
| --- | --- | --- |
| Работа требует пересечения членства задачи и рабочего статуса подзадачи, либо самой задачи при пустом составе | [workFor и analyzeSprints](../../../../../../server/sprint-analysis.ts), [FR-036](../../../../specs/sprint-continuity.md) | Сохранить алгоритм доказательства работы и ADR-0001 |
| Есть состояния work, empty, unknown, active-empty; работа покрывает полный наблюдаемый спринт | [контракт](../../../../../../shared/sprints.ts), [расчёт](../../../../../../server/sprint-analysis.ts) | Повторно использовать полный набор результатов до фильтра интерфейса |
| Старые бреши используют членство, четыре этапа и только доказанные отрицательные интервалы закрытых спринтов | [тесты](../../../../../../tests/sprint-membership-gaps.test.ts), [FR-038/039](../../../../specs/sprint-continuity.md) | Нельзя получить новое число суммированием существующего gaps |
| Фильтр обычной задачи сохраняет участие независимо от работы, внутренние пустые и некоторые неизвестные сегменты | [фильтр](../../../../../../src/SprintRows.tsx), [регрессия](../../../../../../tests/sprint-task-visibility.test.ts) | Новый фильтр заменяет это правило; ожидания AC-088/089 надо изменить, а не удалить |
| В UI состояние unknown рисуется знаком ?, empty — ○, active-empty — ◌ | [SprintRows](../../../../../../src/SprintRows.tsx) | Скрыть эти кнопки на всех уровнях, оставить пояснения полноты |
| Общая ось использует visibleSprints через sprintBounds | [App](../../../../../../src/App.tsx), [SprintRows](../../../../../../src/SprintRows.tsx) | Разделить аналитические границы и отрисовку, чтобы скрытие сегментов не сдвигало шкалу и старые отметки |
| Метрики читаются из EpicTimeline, а sprintAnalysis — отдельная проекция набора | [метрики](../../../../../../shared/metrics.ts), [Jira-набор](../../../../../../server/jira/dataset.ts) | Согласовать доступ к новой метрике в таблице и сортировке; не искать её в исходных Excel-агрегатах |
| Кэш восстанавливает аналитическую проекцию из sprintInputs и hierarchy | [набор](../../../../../../server/jira/dataset.ts), [кэш](../../../../../../server/cache.ts) | Новые сетевые чтения и миграция исходных входов не требуются |

Сохраняется принятое ограничение [ADR-0001](../../../../adr/ADR-0001-current-subtask-sprint-analysis.md): текущие подзадачи используются для всего периода; исторический поиск удалённых и перенесённых объектов не вводится. Статусы и периоды Отложено уже распознаются последним завершённым пакетом.
