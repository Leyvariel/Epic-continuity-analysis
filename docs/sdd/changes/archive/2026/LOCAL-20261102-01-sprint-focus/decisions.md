# Решения от 02.11.2026

## Подтверждено пользователем

| Решение | Ответ и следствие |
| --- | --- |
| D1: критерий работы | Одного включения задачи в спринт недостаточно: нужна подтверждённая работа хотя бы части задачи. Такой спринт покрывает время целиком |
| D2: Отложено | Из всего отрезка между реализацией и экспериментом исключается Отложено, как в основном TTM |
| D3: источник рабочих статусов | Сохранить существующее правило: текущие подзадачи; только при их доказанном отсутствии — сама задача |
| D4: пересечение команд | Для покрытия времени достаточно работы хотя бы одной команды |
| D5: время вне спринтов | Не считать дни между спринтами, когда полный календарь подтверждает отсутствие спринта |
| D6: повторные циклы | Учитывать каждый цикл; незавершённый — до среза |
| D7: незакрытый спринт | Время без работы показывать предварительно до среза; при появлении работы весь спринт может стать покрытым |
| D8: прежние отметки | Добавить только числовую метрику; смысл тёмных отметок пока сохранить |
| D9: закрытие без эксперимента | Окончательное закрытие гипотезы без перехода в эксперимент заканчивает расчёт датой окончательного закрытия |

Первоначальное изложение допускало достаточность одного включения в спринт; D1 явно уточняет и заменяет это прочтение. Скрытие пустых и неизвестных спринтов запрошено отдельно от метрики.

## Предложения, утверждённые в составе пакета

Предложение P1 о границе окончательного закрытия подтверждено пользователем и перенесено в D9. Промежуточное закрытие перед переоткрытием не является окончательным.

- P2: колонка «Без работы в спринтах» размещается после TTM без флага, без нормативной заливки; единицы — календарные сутки по 24 часа.
- P3: число рассчитывается для исходных гипотез; дочерние строки показывают прочерк с пояснением. Процент фокуса пока не добавляется.
- P4: при неопределённости, способной изменить итог, основной показатель неизвестен; в деталях сохраняются доказанные интервалы, предварительная часть и причина неизвестности.
- P5: фильтр подтверждённой работы действует на все три уровня. Пустые и неизвестные сегменты не рисуются и не создают собственные дорожки; аналитические входы и предупреждения сохраняются.

Предложения P2–P5 согласованы общим подтверждением ниже. Предыдущий commit/push относился к расширению статусов и не распространяется на новую работу.
