# Изменение отбора: отельные эпики без префикса статуса

## Добавленные требования

Нет.

## Изменённые требования

### FR-005: Решение о включении

Система ДОЛЖНА включать подтверждённый HF-эпик, у которого ни резолюция, ни текущий статус не означают отклонение (`Отклонено`, `Отклонён`, `Rejected`, `Не будет выполняться` после нормализации). Другие непустые резолюции сами по себе не исключают эпик. Тип эпика определяется по `epicTypeIds` профиля; поток — по единственному префиксу `[HF]` или `[DF]` текущего статуса.

Для подтверждённого эпика проекта HOTELS в одном из трёх согласованных текущих статусов — «Решили делать», «Тестирование эпика», «Релиз» — система ДОЛЖНА разрешать HF-анализ без префикса. Это ограниченное правило не ДОЛЖНО распространяться на одноимённые статусы других проектов, обычные задачи, неизвестные статусы или явный DF. Отклоняющая резолюция и статус по-прежнему исключают эпик. Исторический вход в такой статус сам по себе не заменяет проверку текущего типа и проекта.

Поле «Вид эпика» не заменяет указанные признаки. Неэпики и DF исключаются с причиной, неизвестный поток остаётся неразрешённым. Для доски неразрешённые кандидаты блокируют загрузку историй всей выборки. Существующие правила проверки профиля доски сохраняются; изменение не разрешает автоматически считать любую доску HOTELS проверенной.

#### AC-003: Неразрешённый HF

- **ДАНО** среди кандидатов доски есть задача без подтверждённой принадлежности HF или DF, не подпадающая под разрешённое правило HOTELS.
- **КОГДА** завершается проверка метаданных.
- **ТОГДА** история доски не загружается и аудит показывает причину.

#### AC-103: Отельный эпик в статусе без префикса

- **ДАНО** кандидат принадлежит HOTELS, имеет подтверждённый тип эпика и текущий статус «Решили делать», «Тестирование эпика» или «Релиз», без отклоняющей резолюции.
- **КОГДА** выполняется отбор исходных эпиков.
- **ТОГДА** отсутствие префикса не мешает включению и чтению его истории; в аудите доступно основание включения.

#### AC-104: Границы отельного правила

- **ДАНО** у кандидата такой же статус, но он относится к другому проекту; либо это обычная задача HOTELS; либо отельный эпик отклонён.
- **КОГДА** выполняется отбор.
- **ТОГДА** одно название статуса не включает его как HF: другой проект проверяется прежним правилом, обычная задача исключается по типу, отклонённый эпик — по резолюции или статусу.

## Удалённые требования

Нет.
