## Проверка HOTELS-12351 — 02.11.2026

Источник: [HOTELS-12351](https://hq.tutu.ru/browse/HOTELS-12351). Обе пользовательские ссылки одинаковы. Выполнены только два GET: задача с историей и текущий каталог статусов проекта HOTELS. MCP Jira в этой сессии не предоставлен; использован разрешённый skill способ REST с PAT из Keychain. PAT, авторы изменений, комментарии и описания в пакет не записаны. Приложение не импортировало этот эпик и не заменяло рабочий набор.

Очищенное [свидетельство](evidence/hotels-12351-statuses-20261102.json) содержит 51 запись истории из заявленных 51, начало страницы 0, 8 статусных переходов. Это полнота полученного ответа на момент чтения; повторная сверка `updated` и весь конвейер приложения здесь не выполнялись.

Тип эпика — «Большая задача», ID `6`; он разрешён текущим `epicTypeIds`. Текущий статус — «[HF] Закрыт», резолюция «[HF] Подтверждена». По проверенным метаданным этот образец проходит прежний отбор; это не живая проверка импорта.

Наблюдаемый маршрут: Открыт → Решили делать → Подготовка → Валидация → Проработка решения → Готово к реализации → Реализация → Тестирование эпика → Закрыт. «Решили делать» длился 8 секунд. «Релиз», новые Проверка идей, Отложено и Запланировано в истории этого образца не встречаются; их наличие подтверждает текущий каталог, а не маршрут образца.

## Дополнительное влияние на отбор и дочерние числа

Текущий [адаптер](../../../../../../server/jira/adapter.ts) определяет поток только по префиксу текущего статуса. У трёх разрешённых отельных названий префикса нет: если они текущие, поток будет неизвестен. Следствие проверено по коду, но не воспроизведено изменением реальной задачи. Пользователь 02.11.2026 отдельно разрешил включить поддержку этих текущих состояний в пакет; [дельта отбора](specs/source-selection.md) сохраняет проверки типа, отклонения и границы проекта.

Ответ 5 разрешает статусные числа вложенных эпиков и задач. Их [модель](../../../../../../shared/hierarchy.ts) уже хранит собственные интервалы с длительностями и признак доказанности; [интерфейс](../../../../../../src/App.tsx) сейчас не выводит числовые ячейки. Это отдельное изменение FR-030, а не побочный эффект добавления статуса в общий каталог. Числа детей не должны прибавляться к родителю или сводной статистике корней.

Ответ 6 исключает новые нормы времени и расширение брешей. Общая палитра статусов и числовая цветовая оценка остаются разными сущностями; у новых чисел нельзя автоматически заимствовать пороги другого этапа.
