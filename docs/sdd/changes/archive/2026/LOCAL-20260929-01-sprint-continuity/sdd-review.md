# Итоговая сверка реализации и SDD

Сверена база `9962dac` и накопленное рабочее дерево. Все блоки FR/NFR и их AC из четырёх дельт пакета перенесены в current specs; текстовые различия после нормализации ссылок сводятся к пустым строкам. Требования не удалялись.

| Изменение | Текущий контракт | Реализация и свидетельство |
| --- | --- | --- |
| Спринты задач, Delivery и главного эпика; история членства, категории Sub-task, независимые календари, сохранение | FR-035–041, NFR-002 в [спринтах](../../../../specs/sprint-continuity.md), FR-030/031 в [визуализации](../../../../specs/visualization.md) и [Jira](../../../../specs/jira-ingestion.md) | `server/jira/sprints.ts`, `server/sprint-analysis.ts`, `src/SprintRows.tsx`; T001–T010 в [протоколе](verification.md) |
| Брешь только при доказанном отсутствии включения; отметка касается полосы снизу, цвет сохраняется | FR-038/039, AC-086/087/090/091 | `src/App.tsx`, `src/styles.css`; T014/T016/T017, снимки и геометрия |
| Пустые спринты задачи только внутри открытого периода, участие целиком | FR-042, AC-088/089 | `server/sprint-analysis.ts`; T015, HOTELS-11837 |
| Числа известных этапов при неизвестном начале TTM только для полной Jira-истории | FR-041, AC-092 | `server/timeline.ts`, `server/jira/normalize.ts`; T018, автоматические проверки и replay; визуальная часть открыта |
| Точный аккаунт Keychain и перечитывание PAT | FR-006, AC-093 | `server/jira/keychain.ts`; T019 |
| 17 ключей через запятую, повторы, аудит и совместимость кэша | FR-026/027, AC-094 в [выборе источника](../../../../specs/source-selection.md) | `server/key-candidates.ts`, `server/jira/cache-schema.ts`; T020 |

Согласованы доменная модель, архитектура, эксплуатация, README и навигация. Устранены устаревшие утверждения о числе физических строк, расположении бреши и состоянии пакета. Существенное решение о текущем составе native Sub-task уже закреплено в [ADR-0001](../../../../adr/ADR-0001-current-subtask-sprint-analysis.md); нового архитектурного решения не принято.

Предложение скрывать спринты свёрнутого эпика не реализовано и не включено в текущий контракт. XLSX остаётся за границами новой аналитики. Архивирование не означает полной живой приёмки; [остатки](archive.md) сохраняются.
