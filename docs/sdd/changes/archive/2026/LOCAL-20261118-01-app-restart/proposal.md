# Перезапуск приложения из интерфейса

## Проблема и результат

Для перезапуска локального сервера пользователю приходится обращаться к терминалу. Нужна кнопка, которая перезапускает сервер и возвращает последний сохранённый анализ.

## Область изменения

Кнопка в верхней панели основного приложения, локальный запрос перезапуска, ожидание нового экземпляра и обновление страницы. Во время импорта, обновления, сброса или перезапуска новые операции запрещены. Режимы просмотра не предоставляют перезапуск. Сохранённые данные и профиль Jira не меняются; сборка исходников, обновление Jira и восстановление полностью остановленного сервера не входят в задачу.

## Затронутые возможности и участники

Владелец — текущий репозиторий; возможность `application-runtime`. Действие запускает пользователь локальной страницы. Границы локального API сохраняются.

## Риски и ошибки

Перезапуск возможен только при работающем сервере. Если новый экземпляр не готов за 30 секунд, интерфейс сообщает о неподтверждённом результате и сохраняет показанный анализ. Блокирующих вопросов нет.

## Критерии успеха

- **SC-001**: нажатие меняет экземпляр серверного процесса, затем обновляет страницу; идентификатор сохранённого набора и содержимое файла сохраняются.
- **SC-002**: занятый сервер и режим просмотра отклоняют действие; повторное нажатие не порождает второй перезапуск.
