# Перезапуск приложения

## Добавленные требования

### FR-060: Перезапуск с сохранением анализа

По нажатию «Перезапустить приложение» в основном приложении система ДОЛЖНА перезапустить локальный сервер и обновить страницу после готовности нового экземпляра. Последний сохранённый анализ, исходные файлы и профиль доступа ДОЛЖНЫ сохраняться. Перезапуск не ДОЛЖЕН обращаться к Jira или повторно загружать исходные данные.

#### AC-160: Возврат сохранённого анализа

- **ДАНО** запущенное приложение с сохранённым анализом либо пустым состоянием.
- **КОГДА** пользователь нажимает кнопку.
- **ТОГДА** появляется состояние ожидания; после запуска нового экземпляра страница обновляется и показывает тот же сохранённый анализ либо пустое состояние.

### FR-061: Взаимное исключение и доступ

Система ДОЛЖНА отклонять перезапуск во время импорта, обновления или сброса. После принятия перезапуска она ДОЛЖНА блокировать новые изменения до завершения процесса. Повторное нажатие ДОЛЖНО быть заблокировано. Кнопка ДОЛЖНА отсутствовать в режимах просмотра; API ДОЛЖЕН сохранять ограничения локального доступа и запрет изменений в просмотре.

#### AC-161: Занятость

- **ДАНО** выполняющееся изменение или уже принятый перезапуск.
- **КОГДА** приходит конкурирующий запрос перезапуска либо изменения.
- **ТОГДА** система отклоняет его без прерывания текущей операции и без второго перезапуска.

#### AC-162: Ограничения доступа

- **ДАНО** режим просмотра, внешний источник запроса либо отсутствие обязательного локального заголовка.
- **КОГДА** запрошен перезапуск.
- **ТОГДА** сервер отклоняет его; в режиме просмотра кнопки нет.

### FR-062: Ошибка перезапуска

При отказе или отсутствии готового нового экземпляра в течение 30 секунд после принятия запроса система ДОЛЖНА сообщить об ошибке, сохранить показанный анализ и разрешить повторную попытку пользователя. Автоматически повторять запрос перезапуска НЕЛЬЗЯ. Временная недоступность сервера в пределах ожидания не ДОЛЖНА считаться успехом; старый экземпляр не ДОЛЖЕН вызывать обновление страницы.

#### AC-163: Отказ и недоступность

- **ДАНО** отказ запроса, прежний экземпляр либо временно недоступный сервер.
- **КОГДА** пользователь ожидает перезапуска.
- **ТОГДА** отказ показывается сразу; при принятом запросе ожидание продолжается до нового экземпляра или тайм-аута, успех не подменяется простым ответом прежнего сервера.
