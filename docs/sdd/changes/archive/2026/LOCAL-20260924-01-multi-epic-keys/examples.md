# Контрольные примеры ввода

Примеры воспроизводят пользовательский ввод для AC-018. Это данные для проверки формата; существование задач, принадлежность HF и доступность истории не проверялись. В исполняемых тестах числа и ответы Jira заданы синтетически; результаты приведены в [протоколе](verification.md).

## Смешанный результат на синтетических ответах

```text
TEST-1
неверный ключ
TEST-2
test-1
TEST-3
```

| Вход | Заданный ответ для проверки | Ожидаемое представление |
| --- | --- | --- |
| `TEST-1`, `test-1` | Один подтверждённый HF с полной историей | Одна строка эпика с метриками и календарём; повтор отмечен в аудите |
| `неверный ключ` | Ошибка формата, Jira не запрашивается | Строка «Ошибка», номер 2, понятное пояснение; без чисел и полос |
| `TEST-2` | Отдельная задача не найдена или недоступна | Строка «Ошибка» с именно этой причиной, без утверждения о точном отсутствии задачи |
| `TEST-3` | Подтверждённый DF | Исключение с причиной в аудите по текущим правилам |

Число HF — 1; в медиану и максимум попадает только доказанное значение этого эпика. Исправление строки и новый ввод должны убрать прежнюю ошибку. Если `TEST-2` стал доступным HF, refresh должен заменить его ошибку обычной строкой, не создать обе строки сразу.

## Граничные сценарии

| Вход или событие | Проверяемый результат |
| --- | --- |
| Только две неверные непустые строки | Две строки ошибок в таблице, без обращения к Keychain/Jira и без выдуманной временной шкалы |
| Только пустые строки/оформление | Сообщение о пустом вводе, прежний набор сохранён |
| Все корректные ключи получают отдельные 403/404 | Отчёт со строками ошибок; это не подтверждённое отсутствие HF |
| Глобальный отказ PAT или профиля | Ошибка задания и сохранение прежнего набора; не выдумывать отдельную причину по каждому ещё не прочитанному ключу |
| Есть доказанный TTM, но флаг неполный | Сохранены TTM/статусная шкала; impediment неизвестен по действующим правилам |
| Подтверждённый HF только в первоначальном Открыто | Состояние «TTM ещё не начат», без ошибки ключа |
| Ни у одного включённого HF нет доступной истории | Действующий отказ загрузки с сохранением прежнего набора; это отдельный сбой историй, не неверные ключи |
| Перезапуск после смешанного результата | Корректные эпики и строки ошибок восстанавливаются без сети |
| Предел кандидатов/тела запроса превышен | Явный отказ без усечения; реальные пределы согласуются как часть дизайна |
