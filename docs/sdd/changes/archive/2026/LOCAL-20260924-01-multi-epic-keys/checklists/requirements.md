# Чек-лист качества требований: Ввод нескольких ключей эпиков

Проверять раздел запрошенной стадии. Незаполненные разделы следующих стадий не блокируют согласование предыдущей; для готовности полного пакета к реализации должны быть закрыты все применимые пункты. Для неприменимого пункта указать причину. Сам чек-лист не заменяет решения владельцев и проверку поведения.

## Бизнес-требования

- [x] Проблема и ожидаемый результат сформулированы явно.
- [x] Область изменения и исключения сформулированы явно.
- [x] Участники и границы авторизации названы.
- [x] Каждое изменение поведения отражено в дельта-спецификации.
- [x] У каждого требования есть стабильный ID и наблюдаемое поведение.
- [x] У каждого требования есть подходящие сценарии «Дано/Когда/Тогда».
- [x] Значимые бизнес-последствия сбоев и граничных состояний определены без преждевременного выбора механизма реализации.
- [x] Зависимости и владельцы указаны явно.
- [x] Критерии успеха измеряют результат.
- [x] Блокирующих открытых вопросов БТ после ответа пользователя об ошибочных строках не осталось.
- [x] Целевое поведение не описано как текущее.
- [ ] В БТ не осталось расплывчатых формулировок, противоречий и заполнителей; предложение согласовано его владельцем. Содержательная подготовка завершена, согласование ожидается.

## Функциональные требования и дизайн

- [x] Уточнены применимые сценарии, ошибки, повторы, конкурентность, контракты и совместимость.
- [x] Установлены существующий владелец данных, путь записи и граница атомарного изменения; новые таблицы не предлагаются.
- [x] Исходные файловый, досочный и одиночный сценарии сохранены; согласованное пользователем уточнение ошибок отражено в дельтах и дизайне.
- [x] Описан путь от ввода до сохранения и общей таблицы, включая действующее подключение Jira.
- [ ] Дизайн согласован техническим владельцем; согласование ожидается.

## Готовность к реализации

- [x] Задачи покрывают требования и сценарии, содержат пути, проверки, зависимости и необходимый порядок ввода.
- [x] Этапы не выделены как отдельные результаты: полный результат проверяется одним контрольным условием после задач.
- [ ] Статусы соответствуют фактическим согласованиям; согласования предложения и дизайна ещё ожидаются.
- [ ] Содержательная сверка выполнена; успешная строгая проверка готовности ожидает согласований.

После заполнения чек-листа выполнить структурную проверку и строгую проверку готовности. Их фактический результат указать в отчёте; отметки чек-листа не заменяют успешный запуск.
