# Изменение возможности: жизненный цикл набора

## Добавленные требования

### FR-028: Сохранение и повторная проверка списка

После загрузки система ДОЛЖНА сохранять нормализованных кандидатов и аудит введённого списка вместе с набором. Ручное обновление ДОЛЖНО заново проверить каждый сохранённый корректный ключ, включая прежде исключённые и недоступные; ошибки формата ДОЛЖНЫ оставаться видимыми. Результаты старого набора не подмешиваются, а изменение списка требует нового ввода. Сбой до публикации ДОЛЖЕН сохранять прежний набор по действующему правилу.

#### AC-023: Обновление списка

- **ДАНО** сохранены включённый, исключённый и недоступный ключи.
- **КОГДА** пользователь выбирает «Обновить».
- **ТОГДА** все три корректных ключа проверяются по текущей Jira, ошибки формата остаются в аудите, старые вычисленные эпики не подмешиваются.

Если ранее недоступная задача стала доступной и включена в HF-выборку, её прежняя строка ошибки ДОЛЖНА смениться обычной строкой результата без дублирования. Ошибка формата устраняется новым исправленным вводом, а не повторным запросом Jira.

#### AC-024: Восстановление

- **ДАНО** набор списка сохранён, а сервер перезапущен без доступа к Jira.
- **КОГДА** пользователь открывает приложение.
- **ТОГДА** видны сохранённые эпики и ошибочные строки без новой загрузки.

## Изменённые требования

### FR-021: Ручное обновление

По команде пользователя система ДОЛЖНА заново проверять в Jira сохранённых кандидатов файла либо прямого списка, перечитывать актуальный состав доски или один эпик по сохранённому стабильному `issueId`. Для файла и списка ранее исключённые и недоступные кандидаты остаются во входе. Файл с диска и прежний текст поля повторно не читаются; используются сохранённые нормализованные кандидаты. Для файла также сохраняются контрольные поля и агрегаты, а `source.importedAt` остаётся датой первоначального импорта. Для изменения кандидатов или агрегатов нужен новый импорт либо ввод.

Запрос с устаревшим `datasetId` ДОЛЖЕН получать `STALE_DATASET` (409); для автономного набора возвращается `OFFLINE_SOURCE` (409). Набор прямого ввода, содержащий только ошибки формата, МОЖЕТ обновляться локально без Jira, сохраняя эти строки; для их исправления нужен новый ввод.

## Удалённые требования

Нет.
