# Задачи: ввод нескольких ключей эпиков

## Условия начала

Реализация начата по прямому поручению пользователя 24.09.2026. Формальные статусы [предложения](proposal.md) и [дизайна](design.md) остаются черновыми: техническое согласование в репозитории не зафиксировано. Выполненные проверки записаны в [verification.md](verification.md). Рабочее дерево содержало незакоммиченные исходники до начала работы.

Файлы тестов созданы. Работа велась по [BDD-карте](bdd-scenarios.md) и [циклам TDD](tdd-plan.md): T011–T013 создают по одной стартовой падающей проверке и завершаются на красной фазе. Дальнейшие тесты добавляются перед соответствующими изменениями внутри T001–T010; зелёный результат подтверждается задачей реализации. Красный прогон сам по себе не означает, что требование выполнено; фактические красные и зелёные результаты приведены в verification.md.

До первой правки кода сохранена копия исходной рабочей версии; очищенный архив помещён в `evidence/`. Проверка отката использовала временные каталоги и синтетические кэши. Расширение union и потребителей проверено полной типизацией и регрессией на T017.
