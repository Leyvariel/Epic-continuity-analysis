# ADR-0001: Анализ спринтов по текущему составу Jira Sub-task

## Решение и основание

Использовать текущий доступный native roster parent/subtasks за весь оцениваемый период. Пользователь согласовал E1 в составе пакета 02.10.2026 словами «Пакет согласован». [Принятый дизайн](../changes/archive/2026/LOCAL-20260929-01-sprint-continuity/design.md), [E1 и живой образец](../changes/archive/2026/LOCAL-20260929-01-sprint-continuity/d2-decision.md).

Историческая полнота удалённых и перенесённых подзадач не доказана. Поэтому она не заявляется как свойство анализа. Непустой текущий состав исключает статус родителя даже до создания его текущих подзадач; пустой доказанный состав использует родителя. Найденный перенос либо противоречивый parent переводит вклад соответствующей подзадачи в неизвестность; другая доказанная работа сохраняется.

## Последствия

UI постоянно показывает ограничение текущего состава. Перемещение или удаление подзадачи может изменить результат после обновления. Исторический поиск удалённых объектов и восстановление интервалов parent не входят в эту редакцию. Ограничение и входы сохраняются в кэше; неизвестность не трактуется как отсутствие фокуса. Приёмка реализации отдельно отражена в [протоколе](../changes/archive/2026/LOCAL-20260929-01-sprint-continuity/verification.md).
