# Совместимость с автономным XLSX

## Назначение и ответственность

Сохранённая ветка API позволяет читать прежние книги и кэш без Jira. В форме «Файл» автономная ветка выбирается как «История из XLSX, без Jira»; исходный автономный расчёт корневых метрик сохранён. Формат книги подробно описан в [контракте XLSX](../../legacy-xlsx.md).

## Требования

### FR-024: Автономный импорт

`POST /api/import` без `X-History-Source` или со значением `file` ДОЛЖЕН обрабатывать XLSX без Jira и Keychain. Книга ДОЛЖНА содержать один однозначный лист с ключом, типом эпика, названием и резолюцией. Отбор HF, исключение DF/отклонённых, дубликаты и контроль агрегатов в этом режиме определяются файлом. Книга без пригодных HF-эпиков ДОЛЖНА отклоняться.

#### AC-016: Книга без сети

- **ДАНО** корректная книга старого формата с HF-эпиками, сеть запрещена.
- **КОГДА** вызывается автономный импорт API.
- **ТОГДА** набор сохраняется без исходящих запросов; агрегаты доступны отдельно, отсутствующая история не превращается в календарь.

### FR-025: Предоставленная история

Для календаря книга ДОЛЖНА содержать непрерывные интервалы листа «История» и явный `asOf` листа «Параметры». Пробелы, пересечения, неоднозначное начало либо отсутствие среза не ДОЛЖНЫ компенсироваться агрегатами. Даты без пояса интерпретируются в Москве; текстовая дата без времени не доказывает точный переход.

Лист «Impediment» ДОЛЖЕН задавать полноту флагов: его отсутствие означает неизвестность, наличие с одними заголовками — отсутствие флагов у всей выборки. Расчёт ДОЛЖЕН сохранять срез при повторном открытии; история старого набора не подмешивается в новую книгу.

#### AC-017: Отсутствующий и пустой лист флагов

- **ДАНО** пригодная начавшаяся история TTM и явный срез.
- **КОГДА** лист флагов отсутствует либо присутствует только с заголовками.
- **ТОГДА** в первом случае impediment неизвестен; во втором — ноль, если структура листа корректна.

## Поведение при сбоях и на границах

Ошибка книги до создания задания возвращается через HTTP. Для агрегатов без истории сохранённый v3 имеет `asOf: null`, а время импорта не становится моментом исторического среза. Ручной Jira-refresh такого набора недоступен; для автономного обновления требуется повторный импорт книги; переход в Jira-режим является отдельным выбором пользователя.

## Связанные элементы: реализованное дополнение

### FR-033: Автономное раскрытие по данным книги

Пользователь ДОЛЖЕН иметь возможность загрузить автономную XLSX-книгу через форму файла. В этом режиме система ДОЛЖНА брать связи, метаданные и точную историю связанных элементов из самой книги и показывать их по FR-030 и FR-032 без запросов Jira и Keychain.

История ДОЛЖНА иметь явный общий срез. Данные дочерних элементов не требуют включения их в исходный HF-лист; тип, признак подзадачи и резолюция должны быть определимы по книге. Агрегатные длительности и одни ключи не доказывают связи или календарные интервалы. Обычный режим загрузки ключей CSV/XLSX с чтением Jira сохраняется как отдельный явно выбранный режим.

Старая книга без дополнения ДОЛЖНА открываться по прежним правилам с сообщением «Данные о связях не загружены»; отсутствие листа связей не тождественно пустому списку детей. Ошибка отдельной дочерней истории оставляет другие доказанные данные; неоднозначный общий срез или противоречивые идентификаторы структуры не должны молча объединяться.

#### AC-044: Полный автономный путь

- **ДАНО** книга с исходным HF-эпиком, связями, DF-эпиком, задачой, подзадачей и точными историями.
- **КОГДА** пользователь выбирает автономный режим и загружает книгу при отключённой сети.
- **ТОГДА** исходная строка и раскрытие работают; DF и задача видны, подзадача исключена, обращения к Jira и Keychain отсутствуют.

#### AC-045: Старая книга и дефект истории

- **ДАНО** старая книга без связей и новая книга с разрывом истории одной дочерней задачи.
- **КОГДА** каждая загружается отдельно.
- **ТОГДА** первая сохраняет прежние метрики с сообщением об отсутствии загруженных связей; во второй пригодные дочерние полоски видны, проблемная строка содержит предупреждение.

## Текущие ограничения

Полнота начала истории и флагов зависит от предоставленной книги; внешняя Jira-доказательность здесь отсутствует. Старый расчёт не включает Jira-настройку предрабочего статуса «Решили делать»; одинаковые входные статусы разных профилей не гарантируют одинаковый результат.

Реализация связанных элементов проверена автоматическими сценариями на обоих источниках и живыми образцами Jira. Пользователь подтвердил проверку по ключу и признал её пока достаточной. Полная приёмка XLSX и остальных живых/ручных случаев не заявлена; границы результата и непроверенные остатки T012/T013 — в [протоколе](../changes/LOCAL-20260924-02-linked-issue-status-bars/verification.md).
